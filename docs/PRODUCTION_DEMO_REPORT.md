### 2. ロール別E2Eテストスクリプト
**ファイル**: `test_actual_flow.py`

#### テスト対象

**👑 ADMIN ロール（9項目）:**
1. ログイン
2. 物品一覧取得（全件）
3. カテゴリフィルタ
4. 発注申請管理（承認待ち確認）
5. 発注申請承認
6. 承認済み申請取得
7. 発注書確定→履歴反映
8. 履歴取得
9. CSV出力（在庫）

**🧑‍💼 USER ロール（5項目）:**
1. ログイン
2. 在庫一覧取得（全件見える）
3. 出庫処理（造影剤）
4. 出庫→履歴反映
5. 発注申請作成

**🧑‍🦽 GUEST ロール（6項目）:**
1. ログイン
2. 在庫一覧（部署制限）
3. 出庫候補（部署制限）
4. 他部署専用品除外
5. 出庫処理
6. 発注申請ページ制限

## 重要な検証ポイント

### 1. GUESTユーザーの部署制限
**仕様**: GUESTは「自部署タグ + 全社共通」の物品のみ閲覧・出庫可能

**検証結果**:
- 全体物品: 62件
- 看護部GUEST: 31件（自部署+全社共通のみ）
- 放射線科GUEST: 異なる件数（各部署専用品が異なるため）
- **他部署専用品は完全に除外されている** ✅

### 2. 発注申請→承認→発注書作成→履歴反映フロー
**検証内容**:
1. USER: 発注申請作成（PENDING）
2. ADMIN: 申請を承認（APPROVED）
3. ADMIN: 承認済み申請を選択→発注書確定（ORDERED）
4. 履歴テーブルに「ORDER」として記録

**検証結果**: 全ステップが正常動作 ✅

### 3. 出庫処理→履歴反映
**検証内容**:
1. USER/GUEST: 出庫実行
2. 在庫減算確認
3. 履歴テーブルに「OUT」記録確認

**検証結果**: 在庫・履歴ともに正確に反映 ✅
